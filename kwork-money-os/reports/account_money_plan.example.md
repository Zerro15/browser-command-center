# Kwork Account Money Plan Example

This is a public-safe example. It does not describe a real account, real client messages, or a private revenue strategy.

## Top Services
- Simple Telegram request bot: small scope, clear business result.
- CSV cleanup script: low-risk task with sample input/output.
- One-page parser: public data only, one source, no bypasses.
- Docker launch setup: run a small project with a README.
- Google Sheets notification: one trigger, one message destination.

## Daily Routine
- Check messages manually.
- Use Reply Assistant only to prepare drafts.
- Review every draft before sending.
- Keep first orders small and easy to verify.

## Safety
- Do not push generated private reports.
- Do not store private runtime files or client text.
- Publish, send, save, accept, cancel, and delete actions are manual.
