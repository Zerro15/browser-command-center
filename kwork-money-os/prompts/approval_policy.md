# Approval Policy

Manual approval is always required before:
- publishing a kwork;
- sending any client message;
- changing the live profile;
- deleting anything;
- saving live kwork changes;
- uploading files to a live draft.

Forbidden:
- password in argv;
- password in logs;
- password in JSON/state;
- automatic message sending;
- automatic publication;
- captcha bypass;
- scraping private pages;
- spam.

Allowed without approval:
- local market analysis of public pages;
- local offer generation;
- local banner prompt generation;
- local QA checks;
- dry-run browser flow generation.
