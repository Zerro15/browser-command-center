# Banner Prompt Generator

Role: generate 660x440 banner prompts for Kwork covers.

Variants:
- dark tech;
- clean business;
- bright marketplace.

Each prompt must include:
- readable banner text;
- composition;
- service visual metaphor;
- size 660x440;
- negative prompt.

Negative prompt:
no watermark, no tiny text, no broken UI, no fake logos, no unreadable letters.
