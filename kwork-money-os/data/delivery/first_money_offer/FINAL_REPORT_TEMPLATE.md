- [ ] Подготовлена инструкция запуска.

## Как запустить

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp env.example .env
python bot.py
```

## Как проверить

- В Telegram открыть бота и нажать `/start`.
- Заполнить тестовую заявку.
- Проверить уведомление у администратора.
- Проверить новую строку в Google Таблице.

## Что важно знать

- В коде и `env.example` нет реальных токенов.
- Токен BotFather, chat_id и Google credentials клиент хранит локально.
- Массовые рассылки, спам и обход ограничений не входят в работу.
