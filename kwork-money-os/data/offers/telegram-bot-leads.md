# Сделаю telegram-бот для заявок с понятным результатом

## Short Description
Клиент получает рабочий канал приема заявок в Telegram.

## Full Description
Быстрый бот, который принимает заявки и отправляет их администратору.

Результат: Клиент получает рабочий канал приема заявок в Telegram.

Перед стартом уточняю задачу, фиксирую базовый объем и показываю, что именно будет готово. Если задача выходит за рамки базового кворка, заранее предложу отдельный этап.
