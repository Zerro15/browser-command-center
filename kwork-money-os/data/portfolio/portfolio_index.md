# Portfolio Index

Demo portfolio pack for Kwork profile `ZerroOne`.

The cases are written as examples and reusable templates. They are safe to use as public profile materials if presented honestly.

## Cases

- [Telegram-бот для заявок с записью в Google Таблицу](case_01_telegram_leads_bot.md) - demo project for small business lead capture.
- [Автовыгрузка данных из Яндекс Директа в Google Таблицу](case_02_yandex_direct_to_google_sheets.md) - example solution based on the starter template in `templates/yandex_direct_sheets_exporter/`.
- [Запуск простого проекта в Docker с инструкцией](case_03_docker_project_launch.md) - reusable launch structure for small Python/web projects.

## Profile Text

- Use `kwork_profile_portfolio_text.md` for short profile wording.
- Use `portfolio_upload_checklist.md` before adding cases manually to Kwork.
- Use `banner_prompts.md` to generate neutral demo visuals.

## Manual-Only

Portfolio upload, profile save, moderation, publication, phone/SMS verification, and withdrawal setup remain manual-only.
