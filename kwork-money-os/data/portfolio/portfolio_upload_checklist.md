# Portfolio Upload Checklist

Manual-only checklist before adding portfolio cases to Kwork.

## Before Upload

1. Make sure phone verification is completed manually.
2. Confirm the case is described as a demo, example, or template.
3. Do not claim the case is a paid commercial order.
4. Do not add fake reviews, fake client names, or fake metrics.
5. Remove any private client data if custom files are added later.
6. Use only placeholders for tokens, phones, emails, and credentials.
7. Prepare neutral screenshots or banners that do not expose accounts.

## Manual Upload

1. Open Kwork manually in the visible browser.
2. Add portfolio text manually.
3. Upload visuals manually if needed.
4. Review the public wording.
5. Save or submit only manually after final human review.

## Never Automate

- phone/SMS verification;
- portfolio upload;
- profile save;
- publication;
- moderation submission;
- proposal sending;
- messages;
- withdrawal setup;
- order acceptance/cancellation.
