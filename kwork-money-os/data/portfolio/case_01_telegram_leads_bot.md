# Telegram-бот для заявок с записью в Google Таблицу

## Type

Демо-проект / пример решения / шаблон под задачу клиента.

## Задача

Малому бизнесу нужен простой Telegram-бот, который принимает заявки от клиентов, сохраняет данные и быстро передаёт их менеджеру.

## Что делает решение

- принимает имя, контакт, тип услуги и комментарий;
- проверяет, что обязательные поля заполнены;
- сохраняет заявку в Google Таблицу или локальную базу;
- отправляет уведомление владельцу или менеджеру;
- даёт клиенту понятное подтверждение, что заявка принята.

## Стек

- Python;
- aiogram;
- Google Sheets API;
- SQLite или PostgreSQL;
- `.env` для настроек;
- systemd, Docker или ручной запуск по договорённости.

## Что получает клиент

- рабочий сценарий приёма заявок;
- таблицу или базу с заявками;
- инструкцию запуска;
- список переменных окружения без секретов в коде;
- рекомендации по дальнейшим доработкам.

## Срок

2-4 дня для базовой версии.

## Примерная стоимость

4000-7000 ₽ в зависимости от количества вопросов, интеграций и формата хранения.

## Ограничения

- клиент сам создаёт Telegram bot token через BotFather;
- доступы передаются только безопасным способом вне публичных файлов;
- сложная CRM-интеграция оценивается отдельно.

## Что нужно от клиента

- список вопросов для заявки;
- Telegram bot token;
- Telegram ID получателя уведомлений;
- ссылка или доступ к Google Таблице, если нужна Sheets-интеграция;
- желаемый текст подтверждения для клиента.
