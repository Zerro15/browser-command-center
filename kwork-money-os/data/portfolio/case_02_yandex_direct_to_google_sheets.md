# Автовыгрузка данных из Яндекс Директа в Google Таблицу

## Type

Демо-проект / пример решения / starter template под задачу клиента.

## Задача

Нужно регулярно выгружать статистику из Яндекс Директа в Google Таблицу, чтобы видеть кампании, расходы, клики, показы, CTR и базовые метрики в удобном виде.

## Что делает решение

- читает настройки из `.env`;
- подключается к Yandex Direct API через безопасный skeleton-клиент;
- формирует строки отчёта;
- пишет результат в Google Sheets;
- поддерживает mock mode для проверки без реальных API-ключей.

## Стек

- Python;
- Yandex Direct API;
- Google Sheets API;
- `.env`;
- mock mode;
- unit tests для сборки отчёта.

## Готовый шаблон

Основа уже лежит в:

```text
templates/yandex_direct_sheets_exporter/
```

В шаблоне нет реальных токенов, client data или credentials. Все значения задаются через placeholders в `.env.example`.

## Что получает клиент

- структуру проекта;
- пример `.env`;
- skeleton-клиенты для Direct и Sheets;
- сборку таблицы из mock-данных;
- README и handoff-инструкцию;
- основу для ручного запуска или запуска по расписанию.

## Срок

3-5 дней для первой рабочей версии с согласованными полями отчёта.

## Примерная стоимость

6000 ₽ для базовой выгрузки; 7000-9000 ₽, если нужны дополнительные срезы, фильтры или расписание.

## Ограничения

- клиент сам предоставляет API-доступы;
- пароли не нужны;
- без обхода ограничений Яндекса или Google;
- состав метрик зависит от доступности в API и прав аккаунта.

## Что нужно от клиента

- Yandex Direct token;
- client login;
- доступ к Google Sheets или service account JSON;
- spreadsheet ID;
- список нужных полей и период отчёта.
