# Запуск простого проекта в Docker с инструкцией

## Type

Демо-проект / пример решения / готовая структура для быстрого запуска.

## Задача

Клиенту нужно аккуратно упаковать небольшой проект, чтобы его можно было запускать одной командой на сервере или локально.

## Что делает решение

- добавляет `Dockerfile`;
- добавляет `docker-compose.yml`;
- выносит настройки в `.env.example`;
- описывает команды запуска и проверки;
- добавляет README для клиента;
- фиксирует типовые проблемы запуска.

## Стек

- Docker;
- docker compose;
- Linux;
- `.env.example`;
- Python, Node.js или другой небольшой сервис по задаче клиента.

## Что получает клиент

- понятную структуру проекта;
- инструкцию запуска;
- список переменных окружения;
- команды для rebuild/restart/logs;
- базовый чеклист передачи проекта.

## Срок

2-3 дня для простого проекта.

## Примерная стоимость

3000-5000 ₽ для базовой упаковки; больше, если нужно разбирать сложные зависимости или деплой на сервер.

## Ограничения

- клиент предоставляет исходный код проекта;
- доступ к серверу нужен только если требуется настройка на стороне клиента;
- секреты не добавляются в git и не пишутся в README.

## Что нужно от клиента

- ссылка на репозиторий или архив проекта;
- команда локального запуска;
- список портов и переменных окружения;
- желаемый способ запуска: локально, VPS, Docker Compose;
- ограничения по ОС или серверу.

## Короткий текст для Kwork

Упакую небольшой проект в Docker: подготовлю `Dockerfile`, `docker-compose.yml`, `.env.example` и README с командами запуска, перезапуска, просмотра логов и проверки. Секреты не попадут в код, реальные значения останутся у клиента. Подходит для простого Python/Node.js/web-сервиса или бота.
