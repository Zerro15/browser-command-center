# Kwork Portfolio Pack

Public-safe portfolio materials for the `ZerroOne` Kwork profile.

These are honest demo cases, example solutions, and starter templates. They must not be presented as completed commercial orders, reviews, or client work.

Use this pack for manual profile preparation after phone verification:

- read `portfolio_index.md`;
- pick the most relevant cases for the profile;
- copy the short Kwork-ready text manually;
- upload visuals manually if needed;
- never automate portfolio upload, profile save, moderation, or publication.

Safety:

- no real client data;
- no credentials;
- no email or phone;
- no cookies or browser state;
- no fake testimonials;
- no claim that these are paid orders.
